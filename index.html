◈ Configuration / 03

CAMERA LIBRARY

Each camera has an automatic ID number. You do not need to type an ID or a flag emoji. Changes save in this browser; export HTML to publish them.

Local Save stores changes in this browser on this device. Export updated HTML to embed your edits in a file you can upload to GitHub Pages. This is a static website: the password gate is only a convenience and is not secure authentication.

Feed & privacy note: This dashboard displays only the URLs you configure. A feed may fail if offline, login-protected, blocked from embedding, or incompatible with browser security (especially HTTP feeds on an HTTPS website). Use only cameras you own or have explicit permission to access. Do not expose private camera URLs in a public repository.
